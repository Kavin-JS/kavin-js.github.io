(01) Overview

An offline, real-time wake-word system built on Vosk and SoundDevice, with a live dashboard for confidence tracking and detection statistics, and a virtual LED that lights when the wake word is heard.

Offline recognition

Vosk runs locally: no network, no API keys, and audio never leaves the machine.

Real-time streaming

SoundDevice streams short audio blocks continuously, so detection keeps up with speech.

Confidence, not yes/no

Each detection carries a confidence value, so the threshold can be tuned instead of guessed.

Visible state

A live dashboard and a virtual LED make the system's behaviour observable while it runs.

Interactive · simulated recognizer

Detection lab

The real system recognizes speech offline with Vosk. This lab models what happens next: a noisy transcript is compared with the wake word, turned into a confidence score, and a threshold decides. Raise the noise, move the threshold, and watch missed detections trade off against false accepts.
