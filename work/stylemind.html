(01) Overview

StyleMind AI is the next-generation build of ShonoWear: a full-stack styling platform with a PostgreSQL-backed virtual wardrobe, pretrained computer vision models and an LLM chat interface for outfit recommendations. Code is being finalized before it is published.

Virtual wardrobe

Everything you own, stored in PostgreSQL, so recommendations come from clothes you actually have.

Computer vision

Pretrained vision models read garments from photos, so adding an item is a picture, not a form.

LLM chat interface

Ask for an outfit in plain language and get recommendations grounded in the wardrobe.

Built on ShonoWear

The previous version is public; this build rewrites the stack for a cleaner, more capable platform.

Interactive · colour-theory model

The stylist

A browser model of one part of styling: how colours relate. It scores outfits by hue relationships on an HSL wheel (analogous, complementary, triadic), treats neutrals as free, and rewards lightness contrast. The platform's vision and LLM stages are not simulated here.
