(01) Overview

AIKA is a production-oriented, multi-tenant RAG knowledge platform, built with real security and architectural hygiene rather than as a prototype. It is complete through Identity and Tenancy (v0.2) and validated in Docker at every milestone.

Modular monolith

One deployable unit with hard module boundaries: the simplicity of a monolith, with seams that can be split later if needed.

Strict tenant isolation

Every customer's data stays theirs. The lab below shows why that has to hold in the data layer.

Argon2id authentication

Passwords are hashed with Argon2id, a memory-hard function designed to make large-scale cracking expensive.

Instruction-aware embeddings

Queries and documents are embedded with different instructions, which improves how well they align in vector space.

Interactive · illustrative demo

Tenant isolation lab

Two tenants share one database. Search as each one, then switch the tenant filter off to simulate the classic multi-tenant bug and watch another customer's documents leak into the results.

Password hashing cost
Slow, salted hashing is what makes stolen password databases expensive to crack. This runs a real PBKDF2-SHA256 derivation in your browser. AIKA uses Argon2id, which is memory-hard; browsers don't ship Argon2, so PBKDF2 stands in to show the same cost idea.
