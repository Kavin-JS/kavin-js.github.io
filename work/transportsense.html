(01) Overview

Transport emission analytics written in pure Haskell: a purely functional architecture with type-safe data pipelines, where the type system keeps invalid data out of the calculations.

Pure functions

Every transformation is side-effect free, so it is easy to test and reason about.

Type-safe pipelines

Malformed data is rejected where it enters, as a typed error, not discovered later as a wrong number.

Functional architecture

Data flows through composed functions: parse, transform, analyse, report.

Emission analytics

The pipeline turns cleaned trip data into emissions you can compare and act on.

Interactive · typed pipeline

Typed pipeline lab

TransportSense is written in pure Haskell: raw input is parsed into types before anything is computed, so bad data becomes a typed error instead of a wrong number. This lab mirrors that idea. Add trips, try the bad input, and watch invalid rows get rejected as Left while valid ones flow on as Right. Emission factors are illustrative.
